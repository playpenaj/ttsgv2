📖 Pointing System

Simplified ITTF Rating Points System.

How Points Are Calculated

1. Base Rating: Every player starts with 1000 points.

2. Match Result: Winner gains, loser loses.

3. Point Difference:

  • Higher-rated wins (expected): small gain (1–9 pts).
  • Lower-rated wins (upset): large gain (10–40 pts).

4. ITTF Table (simplified):

  • Diff 0–24: ±10
  • Diff 25–49: ±12
  • Diff 50–99: ±14
  • Diff 100–149: ±16
  • Diff 150–199: ±20
  • Diff 200–299: ±24
  • Diff 300–399: ±28
  • Diff 400–499: ±32
  • Diff 500–749: ±36
  • Diff 750+: ±40

5. Doubles: Uses average rating of each pair.

6. No points until both sides confirm.

Discount Tiers

  • 0–499 points: 0% discount
  • 500–999 points: 5% discount
  • 1000–1499 points: 10% discount
  • 1500–1999 points: 15% discount
  • 2000+ points: 20% discount

Challenge Flow

  1. Player A sends a Challenge.
  2. Player B Accepts or Declines.
  3. Match is played at the chosen CC.
  4. Either side Submits the Score.
  5. The other side Acknowledges the score.
  6. Points are awarded and the match is recorded.

Subscription Rules

  • Monthly: $2
  • Valid for the current calendar month.
  • Required to challenge, accept, and record matches.
  • Admins can enable/disable/extend.
